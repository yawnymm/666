YUHAN YANG — Creative Portfolio

Preview:
1. Download and extract the complete ZIP file.
2. Keep index.html, styles.css, script.js, and the entire assets folder together.
3. Open index.html in a browser.

Important image note:
Do not open index.html from inside the ZIP preview, and do not move index.html away from the assets folder. The site uses relative image paths such as assets/avatar.png and assets/works/page2.jpg. If you upload the site to a hosting service, upload the complete folder structure, including every image in assets/works.

Included:
- index.html: website structure and content
- styles.css: layout, responsive rules, colors, and typography
- script.js: navigation, work filters, image galleries, and reading-cat indicator
- assets/avatar.png: illustrated profile portrait
- assets/pixel-cat.svg: pixel cat indicator artwork
- assets/works/: images extracted and cropped from the provided portfolio PDF
- assets/works/blue-hours-cover.png: updated Blue Hours cover image

Design:
Pink palette is retained. Typography now uses Zen Maru Gothic for a softer, cuter and more consistent Chinese text style; pixel lettering is reserved for small decorative labels. Google Fonts requires an internet connection. If unavailable, the browser falls back to local sans-serif fonts.
